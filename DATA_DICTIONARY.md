# Synthetic data dictionary

Every record is generated by this repository; no external dataset is redistributed. Code and generated data are provided under the repository MIT license. NumPy retains its BSD license. The TTS voice in the demonstration is synthetic narration, not a team member's voice.

## EHR (`data/ehr.csv`)
- `id`: synthetic join key SYN-001 through SYN-090.
- `age`: simulated whole years, 30–75.
- `bmi`: simulated kg/m², 22–37.
- `hba1c`: simulated percent, 6.2–9.8.
- `diabetes_years`: simulated years since diagnosis, 1–18.
- `diagnosis`, `medication_context`: descriptive strings; no medication dosing data.
- `synthetic`: always true.

## Wearables (`data/wearables.csv`)
- `patient_id`: foreign key to `id`.
- `t`: elapsed 15-minute sample index, 0–671. Day 1 starts at synthetic midnight; no actual dates or time zone inferred.
- `glucose`: observed synthetic CGM, mg/dL, blank for missing observations.
- `carbs`: grams logged during the current interval. It is an auxiliary manual log, not a measurement inferred from a wearable.
- `steps`: count in the interval.
- `heart_rate`: synthetic beats/minute.
- `sleep_hours`: latest synthetic daily sleep total.

The generator uses an HbA1c/BMI-related baseline, delayed carbohydrate response, random activity, sleep effects, autocorrelated noise and independent sensor noise. These equations were chosen for software demonstration and lack physiological validation. The dataset supports testing software behavior, not training a clinical device.

## Model artifacts
`model.json`: version, ordered features, selected columns, training means/scales, ridge coefficients, logistic coefficients, eight interval half-widths, validation threshold and event definition. `metrics.json`: split sizes, event prevalence, confusion matrices, regression metrics, onset-only results and bootstrap interval. `parity_fixture.json`: fixed past window and Python features used to check browser parity.

## Reproduction
Run `python src/pipeline.py` from the project directory after installing requirements. It overwrites generated CSVs and JSON artifacts deterministically using seed 2026. The dashboard data bundle is rebuilt from the model and the first six test patients. No downloads, API keys or patient access are required.
