Scenario sandbox

Add a hypothetical meal at the current time and recompute the forecast. This is a model sensitivity check, not a causal treatment prediction.

Data quality

Forecasts pause when the latest CGM is missing or over 25% of the 3-hour window is missing.

Research prototype. No clinical validation, diagnosis, medication advice, or live patient monitoring. Replay uses generated sensor observations.

Evidence you can reproduce

90 synthetic patients, 7 days each. Patients remain in exactly one split: 54 training, 18 validation, 18 test. The six dashboard patients come from the test set.

Evaluation contract

Forecast all eight 15-minute horizons. Classify whether any CGM reading exceeds 180 mg/dL in the next 120 minutes. Classification includes ongoing excursions; onset-only results are reported separately.

Features use only history at or before the forecast time. Test patients never influence scaling, model weights, alert threshold, or interval width.

What these numbers mean

These results show performance in our synthetic world. Training and testing share one simulator, so these scores cannot establish accuracy on real patients, Indian population coverage, or healthcare outcomes.

A focused twin for Type 2 Diabetes

Chakravyuh links a virtual patient's static record with a continuously updated sensor history. Each new observation updates the twin state and generates a two-hour glucose forecast.

Two streams, one forecast

Static: age, BMI, HbA1c, diabetes duration.

Dynamic: CGM history, logged carbohydrate, step count, heart rate, sleep duration and time of day.

Models: standardized ridge regression for trajectories and regularized logistic regression for excursion risk. NumPy training, JavaScript browser inference.

Human review stays central

The dashboard supports investigation of an alert and inspection of missing observations. It records a local review marker for the current replay position.

There is no recommendation engine, dosing model, real sensor integration or EHR connection. A prospective study and clinical oversight would be required before patient use.
